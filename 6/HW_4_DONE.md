## Пояснения

В рамках четвёртого домашнего задания в систему добавлены доп. компоненты, которые нужны для того, чтобы сервис стабильно работал, 
не падал под нагрузкой, не был уязвим, и его было удобно поддерживать.

Что добавилось и зачем
1. WAF (Web Application Firewall)
Добавлен на внешнем контуре перед балансировщиком. Нужен для защиты от популярных атак (SQL-инъекции, XSS, попытки взлома и т.д.). 
Например, если кто-то попробует через форму ввести вредоносный код, WAF это отфильтрует.

2. Load Balancer
Теперь трафик от пользователей не идёт в один экземпляр API Gateway, а сначала попадает в Load Balancer, который распределяет его между разными экземплярами (если они есть). 
Это важно при высокой нагрузке.

3. CI/CD (GitLab)
Без комментариев, маст хэв

5. Grafana + Prometheus
Prometheus собирает метрики со всех микросервисов (например, сколько ошибок, сколько времени ушло на обработку запроса). 
Grafana показывает это в виде графиков. С помощью этого можно понять, когда что-то идёт не так, и быстро найти причину.

6. Sentry
Sentry добавлен для отслеживания ошибок — как на фронте, так и на бэкенде. 
Если у пользователя что-то упало, или у нас внутри возникла ошибка, она сразу появится в Sentry, и мы сможем это быстро починить.

7. AppMetrica
Добавлен компонент Яндекс.Метрики для анализа поведения пользователей: какие страницы открывают, где чаще всего уходят. 
Это нужно для того, чтобы потом улучшать интерфейс и конверсию.

8. SMS.RU
К Notification Service добавлен внешний сервис рассылки SMS. 
Это не обязательно, но полезно — можно будет уведомлять пользователя не только по почте, но и по СМС, например, о подтверждении покупки или отмене события.

9. Yandex Calendar
После покупки билета система может автоматически создать событие в Яндекс.Календаре пользователя, чтобы он не забыл о концерте. 
Это улучшает пользовательский опыт.

## Обязательные компоненты (MUST)

| Компонент                | Зачем нужен                                                                 |
| ------------------------ | --------------------------------------------------------------------------- |
| **WAF**                  | Фильтрация вредоносных запросов, защита от атак                             |
| **Load Balancer**        | Распределение нагрузки между сервисами                                      |
| **CI/CD (GitLab)**       | Автоматическая сборка и выкатывание кода, без этого сейчас никак            |
| **Kafka**                | Асинхронное взаимодействие между сервисами (например, оплата → уведомления) |
| **Redis Cluster**        | Кэширование событий (концертов), чтобы не перегружать базу                  |
| **Grafana + Prometheus** | Метрики, графики, мониторинг, чтобы понимать, что происходит                |
| **Sentry**               | Отслеживание ошибок на фронте и бэке                                        |
